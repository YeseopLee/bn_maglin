## 🏗️ 구현된 주요 컴포넌트

### 1. FloorManager.cs (Assets/Scripts/Core/FloorManager.cs)
**핵심 층 관리 시스템**

#### 주요 기능:
- **층 타입 관리**: Normal, Elite, Shop, Boss, Event, Start 6가지 타입
- **층 진행 규칙**: 
  - 5층마다 엘리트 전투
  - 3층마다 상점
  - 10층마다 보스 전투
  - 랜덤 이벤트 (확률 기반)
- **자동 층 전환**: 콘텐츠 완료 시 자동으로 다음 층 이동
- **게임 리셋**: 플레이어 사망 시 1층으로 리셋
- **진행도 추적**: 현재 층/최대 층 기반 진행률 계산

#### 핵심 메서드:
- `StartGame()`: 게임 시작 (1층부터)
- `StartCurrentFloor()`: 현재 층 시작 (타입별 분기)
- `CompleteCurrentFloor()`: 층 완료 처리
- `ProceedToNextFloor()`: 다음 층으로 진행
- `ResetToFloor(int)`: 특정 층으로 리셋
- `OnContentCompleted()`: 외부 시스템 완료 알림 수신

### 2. FloorInfo 구조체
**층 정보 데이터 구조**
- 층 번호, 타입, 이름, 완료 상태, 현재 층 여부
- 자동 층 이름 생성 ("N층 - 층타입")

### 3. FloorUI.cs (Assets/Scripts/UI/FloorUI.cs)
**층 정보 시각화 UI 시스템**

#### 주요 기능:
- **현재 층 표시**: 층 번호, 타입, 아이콘
- **다음 층 미리보기**: 다음 층 정보 사전 표시
- **진행도 표시**: 슬라이더와 퍼센티지
- **층 타입별 색상/아이콘**: 시각적 구분
- **실시간 업데이트**: FloorManager 이벤트 연동

#### 지원 층 타입별 시각화:
- Start: 파란색 - 시작
- Normal: 흰색 - 일반 전투
- Elite: 노란색 - 엘리트 전투
- Shop: 녹색 - 상점
- Boss: 빨간색 - 보스 전투
- Event: 청록색 - 이벤트

## 🔗 기존 시스템과의 연동

### 1. BattleManager 연동
**전투 시스템과의 통합**
- `StartBattle(BattleStageSO)`: FloorManager에서 층 타입별 전투 시작
- `EndBattleSequence`: 전투 승리 시 `FloorManager.OnContentCompleted()` 호출
- 패배 시 `FloorManager.ResetToFloor(1)` 호출로 1층 리셋

### 2. EventManager 연동
**이벤트 시스템과의 통합**
- `TryTriggerEvent(int floor)`: 층별 이벤트 발생 시도
- `EndEvent()`: 이벤트 완료 시 `FloorManager.OnContentCompleted()` 호출

### 3. ShopManager 연동
**상점 시스템과의 통합**
- `EnterShop(int floor)`: 층 정보와 함께 상점 시작
- `ExitShop()`: 상점 종료 시 `FloorManager.OnContentCompleted()` 호출

### 4. GameManager 연동
**전체 게임 흐름 관리**
- `StartNewGame()`: FloorManager를 통한 게임 시작
- `RestartGame()`: FloorManager 리셋 후 재시작

### 5. BattleStageSO 확장
**전투 스테이지 호환성**
- `CanAppearOnFloor(int floor)` 메서드 추가
- 층별 등장 가능 전투 필터링 지원
