   - 상점/이벤트 완료 후에도 동일하게 처리
   - 매끄러운 게임 플로우 보장

== 게임 플로우 ==

1. MainGame.unity에서 "게임시작" 버튼 클릭
2. MainGameController가 모든 매니저 초기화
3. GameManager.StartNewGame() → FloorManager.StartGame() 호출
4. 1층부터 시작하여 층 타입에 따라 적절한 씬 로딩:
   - 전투층: TestBattleScene 로딩, 해당 층의 BattleStage 사용
   - 상점층: TestShopScene 로딩 (3,6,9층 클리어 후)
   - 이벤트층: TestEventScene 로딩 (확률적으로)
5. 각 컨텐츠 완료 후 자동으로 다음 층 진행
6. 모든 층 완료 시 게임 승리 처리

== 테스트 방법 ==

1. MainGame.unity 씬 실행
2. "게임시작" 버튼 클릭
3. 1층 전투 진행 → 보상 선택 → 자동으로 2층 진행
4. 각 층별로 적절한 컨텐츠 등장 확인:
   - 1~3층: 전투 (이벤트 확률 적용)
   - 4층: 상점
   - 5층: 엘리트 전투
   - 7층: 상점
   - 10층: 보스 전투
