몬스터 스폰 애니메이션 시스템 적용 가이드
========================================

1. 개요
--------
이 시스템은 DOTween을 사용하여 몬스터 스폰 시 자연스러운 애니메이션 효과를 제공합니다.
여러 몬스터가 있을 경우 순차적으로 스폰되며, 각 몬스터마다 스케일, 회전, 색상 페이드, 파티클 효과를 포함합니다.

2. 새로 추가된 파일
------------------
- Assets/Scripts/Battle/MonsterSpawnAnimationManager.cs
- Assets/Scripts/Battle/MonsterSpawnParticle.cs

3. 수정된 파일
--------------
- Assets/Scripts/Battle/MonsterSpawnManager.cs

4. 설치 단계
------------

4.1. 스크립트 배치
- 위의 새로운 스크립트 파일들을 프로젝트에 추가합니다.
- 모든 스크립트가 올바른 네임스페이스(Maglin.Battle)에 있는지 확인합니다.

4.2. 기본 설정
- 게임이 시작되면 MonsterSpawnAnimationManager가 자동으로 생성됩니다.
- MonsterSpawnManager의 Inspector에서 다음 설정을 확인할 수 있습니다:
  * Enable Spawn Animations: 스폰 애니메이션 활성화 여부
  * Use Sequential Spawn: 순차 스폰 여부 (true: 한 마리씩, false: 동시)

5. 사용법
---------

5.1. 기본 사용
- 별도 설정 없이 몬스터가 스폰될 때 자동으로 애니메이션이 적용됩니다.
- 애니메이션 비활성화: MonsterSpawnManager.SetSpawnAnimationEnabled(false)
- 순차 스폰 설정: MonsterSpawnManager.SetSequentialSpawnEnabled(true/false)

5.2. 커스터마이징
MonsterSpawnAnimationManager.Instance를 통해 설정 변경 가능:
- UpdateAnimationSettings(delay, duration, ease): 애니메이션 타이밍 조정
- UpdateParticleSettings(useParticle, duration): 파티클 효과 설정

6. 애니메이션 효과 상세
---------------------

6.1. 스폰 시퀀스
1. 몬스터가 작은 크기(0.1배)에서 시작
2. 파티클 효과 생성 (원형으로 확산되는 노란색 파티클)
3. 스케일 애니메이션 (OutBack easing으로 탄력적 확대)
4. 회전 애니메이션 (360도 회전)
5. 색상 페이드 (투명에서 불투명으로)
6. 점프 효과 (위로 올라갔다가 바운스하며 착지)

6.2. 순차 스폰
- 각 몬스터 사이에 0.3초 간격
- 이전 몬스터 애니메이션이 완료된 후 다음 몬스터 시작

7. 성능 고려사항
---------------
- DOTween을 사용하므로 기존 전투 로직에 영향 없음
- 파티클 효과는 자동으로 정리됨
- 애니메이션 중단 시 자동으로 정상 상태로 복구

8. 디버깅
---------
- MonsterSpawnManager의 Debug Mode를 활성화하면 상세한 로그 확인 가능
- 애니메이션 시작/완료 이벤트를 통해 추가 로직 연결 가능

9. 이벤트 시스템
---------------
다음 이벤트들을 구독하여 추가 기능 구현 가능:
- MonsterSpawnAnimationManager.OnSpawnAnimationStarted
- MonsterSpawnAnimationManager.OnSpawnAnimationCompleted  
- MonsterSpawnAnimationManager.OnAllSpawnAnimationsCompleted

10. 문제 해결
-------------
- 애니메이션이 작동하지 않는 경우: DOTween Pro가 설치되어 있는지 확인
- 몬스터가 나타나지 않는 경우: enableSpawnAnimations 설정 확인
- 성능 문제: useSequentialSpawn을 false로 설정하여 동시 스폰으로 변경
