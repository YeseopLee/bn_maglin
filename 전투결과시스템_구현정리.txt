# 88번 전투 결과 및 승리 조건 처리 시스템 구현 정리

## 📋 개요
- **Task ID**: 88
- **제목**: 전투 결과 및 승리 조건 처리 시스템 구현
- **상태**: 완료 (Completed)
- **의존성**: Task 81 (전투 보상 시스템) - 완료됨

## 🎯 구현 목표
전투 승리/패배 판정과 그에 따른 후속 처리를 관리하는 체계적인 시스템 구현
- 승리 조건: 모든 몬스터 처치
- 패배 조건: 플레이어 체력 0
- 승리 시: 보상 화면 표시, 다음 층 이동
- 패배 시: 게임 오버 화면, 1층으로 리셋 옵션
- 전투 통계: 사용한 카드 수, 받은 피해, 전투 시간 등

## 🏗️ 구현된 주요 컴포넌트

### 1. BattleResultManager.cs (Assets/Scripts/Battle/BattleResultManager.cs)
**핵심 전투 결과 관리 시스템**

#### 주요 클래스 구조:
- **BattleResultType**: 전투 결과 타입 enum (Victory, Defeat, Draw, Timeout)
- **BattleStatistics**: 전투 통계 정보 클래스
- **BattleResult**: 전투 결과 정보 클래스
- **BattleResultManager**: 메인 매니저 클래스 (싱글톤)

#### 핵심 기능:
- **승리/패배 조건 체크**: CheckVictoryConditions(), CheckDefeatConditions()
- **전투 통계 수집**: 카드 사용량, 피해량, 조합 성공률 등 실시간 추적
- **결과 처리**: ProcessBattleResult()로 통합된 결과 처리 흐름
- **이벤트 시스템**: OnBattleResultDetermined, OnStatisticsUpdated 등

#### 통계 수집 항목:
- **기본 정보**: 층 번호, 층 타입, 전투 시간
- **플레이어 통계**: 사용 카드 수, 가한/받은 피해, 소모 마나, 조합 시도/성공
- **턴 통계**: 총 턴 수, 플레이어/적 턴 수, 평균 턴 시간
- **효율성 지표**: 카드당 피해, 턴당 피해, 조합 성공률

#### 고급 기능:
- **배틀 타이머**: 선택적 전투 시간 제한 (기본 5분)
- **실시간 이벤트 연동**: BattleManager, PlayerManager, EnemyManager, ComboManager 이벤트 구독
- **디버그 모드**: 상세 통계 로깅 및 테스트 기능

### 2. BattleResultUI.cs (Assets/Scripts/UI/BattleResultUI.cs)
**전투 결과 표시 인터페이스 시스템**

#### 주요 기능:
- **결과 표시**: 승리/패배 제목, 메시지, 아이콘 표시
- **통계 표시**: 층 정보, 전투 시간, 카드 사용량, 피해량, 조합 성공률
- **버튼 시스템**: 계속하기(승리 시), 재시도(패배 시), 메인 메뉴
- **애니메이션**: 페이드 인/아웃, 스케일 애니메이션
- **사운드 연동**: 결과별 사운드 재생 (AudioManager 또는 AudioSource)

#### UI 구성 요소:
- **메인 UI**: resultPanel, resultBackground, canvasGroup
- **결과 표시**: resultTitleText, resultMessageText, resultIcon
- **통계 표시**: floorInfoText, battleDurationText, cardsUsedText 등
- **색상 시스템**: 결과 타입별 색상 구분 (승리: 녹색, 패배: 적색 등)

#### 시각적 특징:
- **애니메이션 커브**: 부드러운 표시/숨김 애니메이션
- **반응형 디자인**: 결과에 따른 동적 버튼 표시
- **다국어 지원**: 층 타입 한국어 변환, 시간 포맷팅

### 3. 기존 시스템과의 연동

#### BattleManager 연동:
- **CheckBattleEndConditions() 수정**: BattleResultManager 우선 사용
- **기존 방식 Fallback**: BattleResultManager가 없을 때 기존 로직 사용
- **이벤트 연동**: static 이벤트를 통한 안정적인 통신

#### 이벤트 시스템 통합:
- **BattleManager**: OnBattleStarted, OnBattleEnded, OnTurnChanged, OnCardsUsed
- **PlayerManager**: OnHealthChanged, OnManaChanged
- **EnemyManager**: OnAllEnemiesDead, OnEnemyDied
- **ComboManager**: OnComboAttempted, OnComboSuccess

#### FloorManager 연동:
- **승리 처리**: FloorManager.OnContentCompleted() 호출로 다음 층 진행
- **패배 처리**: FloorManager.ResetToFloor(1) 호출로 1층 리셋
- **보상 시스템**: 기존 RewardManager와 완전 호환

## 🔗 시스템 아키텍처

### 전투 결과 처리 흐름:
```
전투 진행 중 → 조건 체크 (실시간)
    ↓
승리/패배 조건 만족
    ↓
BattleResultManager.ProcessBattleResult()
    ↓
통계 완료 → 결과 객체 생성 → 지연 시간
    ↓
BattleResultUI 표시
    ↓
사용자 선택 (계속/재시도/메인메뉴)
    ↓
후속 처리 (다음 층/리셋/메뉴)
```

### 이벤트 연동 구조:
```
BattleResultManager (중앙 통제)
    ↑
각종 매니저 이벤트 → 통계 수집
    ↓
BattleResultUI ← OnBattleResultDetermined
    ↓
사용자 액션 → FloorManager/GameManager
```

## ⚙️ 설정 가능한 옵션

### BattleResultManager Inspector 설정:
- **enableStatistics**: 통계 수집 활성화 여부
- **enableBattleTimer**: 전투 시간 제한 활성화
- **maxBattleTime**: 최대 전투 시간 (기본 300초)
- **victoryDelay/defeatDelay**: 결과 표시 지연 시간
- **showDetailedStats**: 상세 통계 로깅 여부

### BattleResultUI Inspector 설정:
- **애니메이션**: showDuration, hideDuration, 애니메이션 커브
- **색상**: 결과 타입별 색상 설정
- **아이콘**: 결과 타입별 스프라이트
- **사운드**: 승리/패배 사운드 클립

## 🐛 해결된 기술적 이슈

### 1. 이벤트 시스템 오류 수정:
- **Static 이벤트 사용**: BattleManager의 static 이벤트로 안전한 구독
- **올바른 시그니처**: ComboManager의 OnComboAttempted(combination, success) 형식 적용
- **이벤트 매개변수**: OnTurnChanged(turnType, turnNumber) 형식 사용

### 2. 타입 참조 오류 수정:
- **Missing using directives**: Maglin.Cards, Maglin.Core namespace 추가
- **Enemy 데이터 접근**: enemy.EnemyData.MaxHealth 형식으로 수정
- **Color 정의**: Color.orange 대신 new Color(1f, 0.65f, 0f) 사용

### 3. AudioManager 연동 오류 수정:
- **Reflection 기반 접근**: 타입 안정성을 위한 동적 호출
- **Fallback 메커니즘**: AudioManager 없을 시 AudioSource 직접 사용
- **안전한 사운드 재생**: null 체크 및 예외 처리
