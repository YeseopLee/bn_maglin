상점 시스템 구현 정리
======================

## 구현 완료 사항

### 1. ShopSO (ScriptableObject) 개선
- 기존: 수동으로 아이템 목록을 설정해야 했음
- 개선: 동적으로 카드와 유물을 Resources 폴더에서 로드
- 카드 타입별 가중치 설정 기능 추가 (Element, Active1, Active2)
- 각 카드 타입별 개별 가격 설정
- 고정된 슬롯 수: 카드 5개, 유물 3개
- 서비스 기능: 카드 제거, 체력 회복

### 2. ShopManager 업데이트
- 새로운 ShopSO 구조에 맞게 수정
- 카드 제거 서비스 중복 사용 방지 로직 추가
- 카드 제거 UI 요청 이벤트 시스템 구현
- FloorManager와의 연동 개선
- 플레이어 덱 카드 목록 제공 기능

### 3. ShopUIGenerator (Editor Tool) 생성
- Tools > Generate Shop UI 메뉴 추가
- 자동으로 상점 UI 생성:
  * 플레이어 상태 (골드, 체력) 표시
  * 카드 판매 슬롯 5개
  * 유물 판매 슬롯 3개
  * 카드 제거 서비스 슬롯
  * 체력 회복 서비스 슬롯
  * 나가기 버튼
- 카드 제거 UI도 별도 생성 가능
  * 플레이어 덱 카드 목록 스크롤 뷰
  * 카드 선택 및 제거 기능
  * 취소 버튼

### 4. ShopUIManager 생성
- 상점 UI 전체 관리
- ShopManager와 PlayerManager 이벤트 연동
- 동적으로 UI 참조 찾기 및 연결
- 아이템 슬롯 자동 업데이트
- 구매 가능/불가능 상태 표시
- 카드 제거 UI 관리
- 실시간 플레이어 상태 업데이트

## 주요 기능

### 상점 시스템
1. **동적 아이템 생성**
   - Resources/Cards 폴더의 모든 카드 자동 로드
   - Resources/Relics 폴더의 Common 타입 유물 자동 로드
   - 카드 타입별 가중치 기반 선택

2. **가격 시스템**
   - 카드 타입별 개별 가격 설정
   - 유물 고정 가격
   - 가격 배수 적용 가능
   - 유물 효과에 의한 가격 변동 지원

3. **서비스 기능**
   - 카드 제거: 1회 제한, 플레이어 카드 선택
   - 체력 회복: 현재 체력에 따른 동적 가격

### UI 시스템
1. **자동 UI 생성**
   - Editor Tool로 완전한 상점 UI 생성
   - 반응형 레이아웃 (Grid, Layout Group 활용)
   - 카드 제거 전용 UI 포함

2. **실시간 업데이트**
   - 플레이어 상태 실시간 반영
   - 구매 가능/불가능 상태 시각적 표시
   - 아이템 구매 후 즉시 UI 업데이트

3. **사용자 친화적 인터페이스**
   - 직관적인 슬롯 배치
   - 가격 정보 명확 표시
   - 구매 완료 시각적 피드백

## 기술적 개선사항

### 성능 최적화
- 카드/유물 데이터 캐싱
- UI 참조 자동 찾기 시스템
- 이벤트 기반 업데이트로 불필요한 UI 갱신 방지

### 확장성
- 새로운 카드/유물 자동 반영
- 카드 타입별 가중치 조정 가능
- 상점 종류별 다른 설정 지원 구조

### 코드 품질
- 싱글톤 패턴으로 매니저 간 안전한 참조
- 이벤트 시스템으로 느슨한 결합
- 디버그 모드로 개발 중 모니터링 지원

## 사용법

### 1. 상점 UI 생성
```
Unity Editor > Tools > Generate Shop UI
```

### 2. 상점 진입
- FloorManager가 상점층에서 자동으로 ShopManager.EnterShop() 호출
- ShopUIManager가 자동으로 UI 업데이트

### 3. 상점 설정
- ShopSO 에셋에서 가중치 및 가격 조정
- 새로운 카드/유물은 Resources 폴더에 추가하면 자동 반영

## 테스트 방법

### TestShopScene에서 테스트
1. TestShopScene.unity 로드
2. Tools > Generate Shop UI로 UI 생성
3. ShopManager 컴포넌트 추가
4. ShopSO 에셋 생성 및 할당
5. Play 모드에서 ShopManager.EnterShop() 호출

### 통합 테스트
- FloorManager와 연동하여 상점층 진입 테스트
- 다양한 카드/유물 조합으로 상점 생성 테스트
- 카드 제거 기능 전체 플로우 테스트
