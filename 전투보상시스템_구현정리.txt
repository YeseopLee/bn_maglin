## 🎯 구현 목표
전투 종료 시 층 타입에 따른 차등 보상 지급 시스템 구현
- 일반층: 소량 골드 + 카드 3종 중 1개 선택
- 엘리트층: 중간량 골드 + 유물 3종 중 1개 선택  
- 보스층: 대량 골드 + (보스유물 1종 + 일반유물 2종) 중 1개 선택

## 🏗️ 구현된 주요 컴포넌트

### 1. RewardManager.cs (Assets/Scripts/Battle/RewardManager.cs)
**핵심 보상 관리 시스템**

#### 주요 기능:
- **층 타입별 보상 생성**: FloorType에 따른 차등 보상 시스템
- **보상 풀 관리**: 카드/유물 풀 관리 및 랜덤 선택
- **보상 적용**: PlayerManager와 연동하여 실제 보상 지급
- **이벤트 시스템**: 보상 생성/선택/완료 이벤트 관리

#### 핵심 메서드:
- `ShowBattleRewards(int currentFloor, FloorType floorType)`: 보상 표시 시작
- `GenerateRewardsForFloor(int currentFloor, FloorType floorType)`: 층별 보상 생성
- `SelectReward(RewardItem selectedReward)`: 보상 선택 처리
- `ApplyReward(RewardItem reward)`: 선택된 보상 적용

#### 층 타입별 보상 로직:
- **Normal/Start층**: 카드 3종 중 1개 선택 + 소량 골드
- **Elite층**: 엘리트 유물 3종 중 1개 선택 + 중간량 골드
- **Boss층**: (보스유물 1개 + 일반유물 2개) 중 1개 선택 + 대량 골드

### 2. FloorTypeReward 클래스
**층 타입별 보상 설정 데이터 구조**
- 층 타입별 개별 설정 가능
- 골드 기본량 및 배수 설정
- 최대 선택 가능 보상 수 설정
- 보상 풀 참조 지원

### 3. RewardUI.cs (Assets/Scripts/UI/RewardUI.cs)
**보상 선택 인터페이스 시스템**

#### 주요 기능:
- **보상 시각화**: 보상 타입별 아이콘, 색상, 설명 표시
- **선택 인터페이스**: 클릭 선택 및 확정 버튼 시스템
- **애니메이션**: 보상 화면 표시/숨김 애니메이션
- **동적 UI 생성**: 프리팹 기반 보상 아이템 UI 생성

#### UI 구성 요소:
- **RewardItemUI**: 개별 보상 아이템 UI 구조
- **색상 테마**: 보상 타입별 색상 구분 시스템
- **애니메이션**: 스케일 기반 표시/숨김 효과
- **이벤트 연동**: RewardManager와 완전 연동

### 4. RewardConfigSO.cs (Assets/Scripts/Battle/RewardConfigSO.cs)
**보상 시스템 설정 관리 ScriptableObject**

#### 주요 기능:
- **층별 기본 설정**: 각 층 타입별 골드량, 배수 설정
- **보상 풀 관리**: 카드/유물 풀 중앙 관리
- **설정 검증**: 보상 설정 유효성 검사
- **자동 적용**: RewardManager에 설정 자동 적용

#### 기본 설정값:
- **일반층**: 기본 골드 15, 배수 1.0x
- **엘리트층**: 기본 골드 25, 배수 1.5x
- **보스층**: 기본 골드 50, 배수 2.0x
- **시작층**: 기본 골드 10, 배수 0.5x

## 🔗 기존 시스템과의 연동

### 1. FloorManager 연동
**층 완료 시 보상 시스템 자동 호출**

#### 수정된 주요 메서드:
- `CompleteCurrentFloor()`: 전투층 완료 시 보상 표시 로직 추가
- `ShouldShowRewards(FloorType)`: 보상 표시 대상 층 판정
- `ShowBattleRewards()`: RewardManager 호출 및 이벤트 연동
- `OnBattleRewardsCompleted()`: 보상 완료 후 다음 층 진행

#### 연동 흐름:
```
전투 승리 → FloorManager.CompleteCurrentFloor() 
→ ShouldShowRewards() 판정 → ShowBattleRewards() 
→ RewardManager.ShowBattleRewards() → 보상 선택 화면 표시
→ 보상 선택 완료 → 다음 층 진행
```

### 2. PlayerManager 연동
**보상 적용 시 플레이어 상태 업데이트**
- `AddGold(int amount)`: 골드 보상 적용
- `AddRelic(RelicSO relic)`: 유물 보상 적용
- 카드 보상: CardManager 구현 시 연동 예정

### 3. 기존 RewardSO 호환성
**StageType ↔ FloorType 변환 시스템**
- `FloorTypeToStageType()`: FloorType을 StageType으로 변환
- 기존 RewardSO 구조와 완전 호환
- 기존 보상 데이터 재사용 가능
